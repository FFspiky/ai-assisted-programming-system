# 算法造物工坊

更新：2026-10-14。首版包含鱼群共舞、排序编舞、海岛寻路三个受约束的创作主题。

## 使用

打开 `/workshop.html`。原 `/learn-analytics.html` 入口也进入工坊；旧学习记录页仍在
`/learning-records.html`，原 `#leaderboard` 链接会转到对应记录页。首页、题库和练习页面保留。

1. 访客可以浏览三个内置示例、暂停回放、拖动进度和改变配色。
2. 登录后修改 Python 或参数，点击“运行我的规则”。访客从工坊点击登录时会临时携带
   当前草稿，登录返回后恢复（仅当前浏览器标签页，30分钟有效）。代码由原有 Docker 执行器运行，
   仅输出一份 JSON 轨迹，后台校验后交给 p5.js 绘制。没有宿主运行回退。
3. 点击 AI 按钮才发送当前主题、参数、代码和创意描述。不发送题库、隐藏用例、其他用户
   数据或 API 密钥。AI 返回作品名、说明、候选参数和候选 Python；不自动应用或执行。
4. 预览后可应用、拒绝或撤销应用。生成中继续编辑会使候选过期；应用后继续编辑时，
   旧快照撤销按钮禁用，避免覆盖新修改。
5. 真实运行完成后保存作品。每个版本绑定不可变运行记录，包括源代码、参数、实际轨迹、
   执行信息、候选来源及配色。改动规则后必须重新运行才能保存。
6. 在“我的造物集”打开作品，刷新恢复，或回看旧版本。保存旧版本会新增版本。
7. 导出 PNG 或离线 HTML。HTML 内嵌固定版本 p5.js、渲染代码、实际轨迹、源程序、参数与
   来源信息，无需联网即可回放；离线文件不会执行或重新验证 Python。

## 范围和判断边界

- 当前创作代码只支持 Python 标准库。原刷题仍支持 Python / C++。
- 创作画面是有限步轨迹回放；修改参数后需再次运行，不是任意代码的实时通用可视化。
- 鱼群最多72帧、18个点；排序最多160帧、16个数字；寻路固定14×10格。
- 画面协议校验检查坐标、长度、有限数值、排序元素守恒及路径相邻/不穿墙。
  可回放不等于算法正确、最短路径已证明或学习效果已提高。
- 内置例子的轨迹由 `scripts/verify_workshop.py` 在 Docker 中生成，并使用代码与参数哈希
  检查录制是否匹配。页面区分“内置代码 · 示例回放”“你的运行 · Docker”“规则已改变 · 旧回放”。
- 每用户最多50件作品，每件最多100个版本。运行12次/分钟，AI请求5次/分钟。
  未配置 Redis 时限流仍为原有的进程内实现；并非公网多进程容量验收。
- 保存使用账号归属、CSRF和版本条件更新；旧页面不能覆盖另一个页面的新版本。
- 实际运行失败或轨迹不合法时不保存运行记录、不换成模拟动画。
- AI请求的参数/代码格式校验不证明候选语义正确；必须由用户运行、观察和决定。

## 数据和接口

迁移：`h96a20261014`，继承 `g85a20261014`。新增四张表：

| 表 | 内容 |
| --- | --- |
| workshop_suggestion | 用户请求、基础版本哈希、AI候选、提示词版本及可获得的模型标识 |
| workshop_run | 一次真实成功运行的输入快照与校验后的可视化数据 |
| workshop_project | 作品归属、名称、主题及当前版本号 |
| workshop_version | 作品版本与运行快照、配色的关联 |

`/api/workshop/catalog` 为公开目录。其余运行、生成、作品及版本接口要求登录，数据仅对
所属账号开放，响应使用 `private, no-store`。请求体上限96KB、代码上限12000字符、
描述上限1200字符。输出仍沿用现有执行器20KB限制。

AI使用统一客户端和现有 `.env` 配置；提示词 `workshop-create-v1`。服务商返回的
`response_model` 仅在确实收到时保存，不从配置补造。来源区分内置代码、人工编辑、
原样AI候选及修改过的AI候选，不推断人工思考过程。

## 运行与验证

Windows PowerShell，项目根目录：

```powershell
.\.venv\Scripts\python.exe -m flask --app app db upgrade
.\.venv\Scripts\python.exe app.py
```

已有数据库升级前先备份。此次本机备份为
`tmp/backups/pre-workshop-20261014-174333.db`。迁移不修改既有题目、账号或提交数据。
若回退程序，先停止服务；恢复备份会舍弃升级后新建的工坊记录，应先另存所需作品。

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_workshop -v
.\.venv\Scripts\python.exe scripts/verify_workshop.py
# 需要更新内置示例录制时，实际运行后再写入：
.\.venv\Scripts\python.exe scripts/verify_workshop.py --write-previews
```

浏览器测试 `tests/smoke/workshop.spec.mjs` 使用隔离数据库副本和测试账号，覆盖访客、
真实运行三主题、版本保存/恢复、离线导出、AI候选过期及撤销、失败重试和窄屏。
AI回复使用明确的测试替身，没有产生真实模型调用费用。模型真实创作质量尚需另行联调。

只引入了固定的 **p5.js 1.11.10** 官方未修改构建，保存在
`static/vendor/p5-1.11.10/`，附 LICENSE、NOTICE 和 SHA-256。

开发过程中使用AI辅助，不把第三方图形引擎或通用算法宣称为自研。

当前可展示的贡献是“创意—可编辑规则—真实执行—视觉作品—版本回看”的完整体验。
参赛材料需要另外保留真实创作案例、人工选择与修改说明，以及现场运行或明确标注的录制。
