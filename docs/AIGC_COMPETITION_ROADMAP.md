# CodeLab 当前实现与验收边界

## 产品定位

编程学习助手，主流程为「验证 AI 代码 → 解释修改 → 独立再做一次」。支持 Python 3.11 / C++17，使用 DeepSeek 官方 API。

## 当前实现

- 题库与代码执行：分类筛选、公开用例与隐藏判题、Docker 隔离执行。
- 学习共创：题目驱动的候选生成、代码质检、解释保存与关联练习。
- 分级帮助：用户主动选择帮助程度，建议绑定实际提交及执行证据。
- 修改复盘：差异预览、采纳、拒绝、撤销与正式复测关联。
- 实战任务室：需求确认、代码开发、真实验收、受控变更及交付导出。
- 问卷推荐：依据用户自述推荐项目，进度来自实际项目记录。

当前运行说明见 [启动与验证](COMPETITION_PREVIEW.md)，功能协议见 [共创说明](CO_CREATE.md)、[学习共创](CO_CREATE_LEARNING.md)、[任务室](TASK_ROOM.md) 和 [提示词说明](AI_PROMPTS.md)。

## 验收原则

以当前代码的测试、迁移和实际运行结果判断完成情况。候选代码与模型解释不能代替执行证据；公开证据不足时不强行定位。界面须区分已完成、处理中、失败和未验证状态。

自动化检查使用独立数据库，不覆盖用户数据。真实 AI 质量、真实学生体验和教学收益需分别采集证据，不能用测试替身、有限用例或一次通过推断。

## 版本与数据边界

旧场景共创已停止新建和修改，已有记录只读。工坊运行代码已移除，数据库迁移链及已有记录保留，避免升级时误删数据。现有功能复用公共的权限校验、版本控制和执行器。
