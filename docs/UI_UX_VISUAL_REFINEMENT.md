# 智练 CodeLab 前端视觉精修方案

2026 年 10 月 13 日 · 蓝白雾光修订版 · 保留原版功能页框架

本版以用户提供的 DeepSeek Harness 首屏截图为颜色依据：蓝色、白色雾光和深蓝底共同构成背景，产品界面保持清晰。首页继续作为产品展示页；导航、题库、练习页沿用项目现有框架。团队展示移除。

上一版的纯炭黑方向、厚胶囊导航、题库新增搜索筛选、练习页拆分面板以及下方统一双列卡片，不再作为实施方案。

## 1 设计边界

| 区域 | 保留 | 本版调整 |
| --- | --- | --- |
| 全站导航 | Logo / 首页、刷题、学习分析 / 访客、登录注册、头像；原三组布局 | 配色、链接状态、图标与文字颜色；不添加胶囊容器、粗边框或悬浮底板 |
| 首页 | 产品展示职责，hero → 产品演示 → 功能介绍 → 页脚 | 蓝白氛围、大标题、真实界面演示、章节布局与动效 |
| 题库 | “选择题目”标题、原卡片网格、题名、难度、右下“选择” | 仅颜色、背景材质与交互色；不加入搜索、筛选、统计条或新信息结构 |
| 练习页 | 题目导航 → 题面 → 编辑器 → 标准输入 → 运行结果 → 分级帮助 | 仅配色、材质和状态颜色；不换编辑器，不拆成新面板，不增加固定右栏 |
| 编辑器 | 语言、AI 优化、运行、提交；辅助方式、帮助程度、补全、草稿；输入与输出的位置 | 按钮颜色、控件边界、代码底色、可读性 |
| 达菲郁 | 原角色、桌宠入口、浮动聊天窗口、上下文附带与帮助设置 | 蓝灰毛玻璃、消息色和边缘亮线 |
| 团队区 | 按用户要求移除 | 功能区衔接结尾 |

功能页的容器宽度、区块顺序、内容密度、原有 ID 和事件绑定优先保留。窄屏仅做防溢出适配，不借响应式名义重排业务。预览的顶部“首页 / 题库 / 练习页”和暂停开关是方案查看工具，不进入正式产品导航。

此前已阅读这些公开产品页。Harness 源码中的 `#0A0A0A` 是基础底色，不能代表叠加动态背景后的视觉结果；本轮纠正了仅按该值推断纯黑首屏的处理。蓝白背景以用户截图为准，不复制 DeepSeek 的 Logo 或鲸鱼商标。

Harness 的局部材质参考仍有效：导航约 12px 模糊，产品侧栏 `blur(32px) saturate(125%)`。来源：[基础样式](https://www.deepseek.com/_next/static/css/25f198211a7e1205.css)、[页面样式](https://www.deepseek.com/_next/static/css/5adb47a13a2794be.css)。以下数值是 CodeLab 的适配方案，不声称是参考站的完整配色或动效参数。

## 3 配色与材质

| 用途 | 建议色值 / 材质 |
| --- | --- |
| 全站底色 | `#0D1B2D`，带少量蓝色环境光 |
| 首屏底色 | `#233E60 → #1A365A → #0D1B2D` |
| 首屏雾光 | 左上蓝白 `rgba(218,236,249,.62)`、中部蓝 `rgba(84,145,222,.66)`、右侧淡蓝白 `rgba(194,220,244,.36)` |
| 主面板 | `#172C44` / `#213A56` |
| 代码正文 | `#101F32` 实底，不做透光背景 |
| 主文字 / 次文字 | `#F2F7FD` / `#B1C3D8` |
| 品牌与交互 | `#A5C9FF` / `#629EFF` |
| 章节背景 | 统一 `#0D1B2D`，使用低透明蓝色环境光柔和衔接，取消整段浅色反转 |
| 成功 / 失败 | `#A0E0CD` / `#FFB8BD`，同时使用“通过 / 未通过”文字 |
| 普通边线 | `rgba(185,214,249,.18)` |
| 毛玻璃 | 蓝灰半透明底 + `blur(24px) saturate(125%)` + 细亮边 |

蓝白主要出现在英雄背景、标题强调、选择按钮、焦点和玻璃边缘。功能页继续以安静的深蓝实底承担阅读；避免每张卡都发光。

玻璃用于首页产品窗口外框、演示窗口顶栏和达菲郁浮层。题目、代码、标准输入、输出、证据采用实底。原导航不新增玻璃容器。题库维持原卡片结构，不新增毛玻璃工具栏。

不支持 `backdrop-filter` 时回退到不透明蓝灰面板。正式实现提供 `-webkit-backdrop-filter`。动画光层不穿过正文，暂停后仍保留完整配色。

## 4 首页章节与演示对应关系

首页采用五种节奏交替：蓝白首屏 + 宽幅产品窗口、开放式左右图文、深蓝横贯章节、角色与玻璃聊天浮层、不等宽的收尾卡片。统一颜色和字形，变化由内容组织产生。分级帮助区沿用全页深蓝底、蓝白标题与灰蓝正文，取消上一版浅色背景和深色文字的反转；区块边缘的环境光自然衰减，避免出现突兀色块。

### 首屏

文案：

> 写下代码。
>
> 让每一步，都更明白。
>
> 练习 Python 与 C++，看懂运行反馈，按需获得一点帮助。
> 和达菲郁一起，把一道题，变成自己的理解。

主操作“开始练习”，次操作“了解核心功能”。使用蓝白柔光而非单纯黑底；标题浮现，正文保持足够对比度。导航直接排在背景上，沿用原版三个分组。

### 产品主演示

使用原练习页的纵向结构，题目导航、题面、工具栏、辅助设置、编辑器、标准输入和结果按原顺序出现。预览与完整练习页共用同一套展示模板；首页只压缩题面篇幅和编辑区高度，并标注“题面节选”。正式落地应复用当前页面样式或截取当前页面，不能重新设计一套假产品 UI。

演示选用当前题库已有的“3的幂”：

1. 编写：先只判断 `n > 0 and n % 3 == 0`。
2. 运行：输入 45，示例输出 true；与题目预期 false 不同。
3. 获得线索：思考“能被 3 整除”是否足以证明“是 3 的幂”。
4. 修改：反复除以 3，检查最后是否剩下 1；同样输入得到 false。

步骤按钮可手动切换，自动演示每步约 4.2 秒。手动选择后停止自动轮换，避免打断阅读。所有结果明确为演示，不冒充真实执行或实时 AI。

### 下方内容

| 文案主张 | 对应原界面 | 演示表达 |
| --- | --- | --- |

| 卡住的那一刻，有人陪你理清思路 | 原达菲郁聊天窗 | 点击“附带当前练习”，出现题目、代码、输入与输出的上下文提示；再显示有针对性的示例对话 |
| 熟悉的题库，随时进入状态 | 原题库卡片 | 真实题名、难度和“选择”按钮；进入同一练习预览 |

AI 优化整合在主演示与练习页，不另加不相关的装饰代码卡。积分、排行榜保留原功能，但本轮不强塞独立宣传区。学习分析不再用项目没有的活动热图替代现有界面。未闭环的问卷学习路径不作为当前核心能力宣传。

## 5 动效设计

| 场景 | 动效 | 目的 |
| --- | --- | --- |
| 首屏 | 缓慢蓝白雾光移动，24 秒往复 | 形成柔和空间感，不干扰阅读 |
| 主标题 | 约 1 秒淡入并向上浮现，两行错开约 140ms | 建立标题层级 |
| 章节标题、产品局部 | 进入视口后一次上浮约 30px，800–900ms | 引导阅读次序 |
| 编写 / 运行 / 帮助 / 修改 | 原界面内容随步骤变化，短距离淡入 | 解释实际操作因果 |
| 用例切换 | 选中亮边和底色过渡 | 让视线跟随当前用例 |
| 四级帮助 | 文案、编号、代码局部切换 | 清楚展示每一级帮助差异 |
| 上下文附带 | 提示条出现，约 400ms | 告诉用户本次对话带上了什么 |
| 达菲郁 | 首次进入视口挥手；附带上下文或发送消息时说话回应；点击角色播放一次短舞，之后恢复眨眼待机 | 使用现有素材动作，让陪伴与操作关联 |

不使用滚动劫持，不自动播放声音。背景、角色与演示离开视口时暂停；切换功能页或隐藏页面时停止自动演示。提供总暂停开关，并尊重 `prefers-reduced-motion`，减少动态效果时直接展示可读内容。展示窗口维持稳定高度，代码变化不造成整页跳动。

## 6 工程实施范围

沿用 Flask/Jinja、原生 JavaScript 和原业务接口。此次交付仍为独立设计预览和方案修订，尚未替换业务模板、样式与脚本。

后续实施建议：

1. 首页新增限定作用域的蓝白背景与章节样式，调整演示、文案、动效，移除团队区。
2. 全站抽出颜色与材质变量；导航只覆盖颜色，不重写布局。
3. `problem_selector.html` 只替换原卡片、标题、按钮的配色。
4. `practice.css`、`evidence.css` 只调整面板、控件、文本和状态颜色。保留模板层级、ID、代码输入、业务事件和草稿存储。
5. 达菲郁聊天保持原拖动、缩放、关闭、恢复与上下文策略，只换视觉材质。
6. 按原页面结构逐页扩展至分析、个人、认证与管理界面。

重点保护：运行与提交区分、四级帮助策略、学习 / 自由模式、旧证据保护、提交代码快照、登录回跳、草稿账号隔离、CSRF 与 SSE。首页演示不连接判题、AI 或账户接口。

原 CSS 存在重复通用选择器，正式改造需要限定页面范围，不能在文件末尾用全局 `.card`、`.btn`、`header` 覆盖造成串页。

## 7 预览范围与验证

当前独立预览包含首页、题库和练习页。题库使用现有题目标题；首页和完整练习页共用同一展示结构。预览可切换语言、运行 / 提交预置示例、查看四级帮助、应用“3的幂”的修改示例、验证旧结果提示、打开助手与附带上下文。其他题目显示对应题面摘要与示例，不假装执行任意代码。

桌面已检查三页结构与页面切换；“3的幂”的错误示例、分级帮助、应用修改后旧证据提示、再次提交通过已通过交互验证。约 1569px、456px 和 321px 实际内容宽度已检查，三页无横向溢出。已验证暂停开关、Python / C++ 切换、玻璃助手和上下文附带；助手计算样式为 `blur(24px) saturate(1.25)`，角色图片加载成功，浏览器未记录脚本错误。此处验证的是设计预览，不是原业务链路验收。

## 8 Skill 使用

继续使用本机已安装的 UI/UX Pro Max。本轮采用其关于减少动态效果、避免滚动劫持、保持导航与交互一致性的建议；具体配色以用户参考截图为准。独立预览用于查看实际效果，不将 Skill 的通用布局建议凌驾于“保留原框架”的要求。

首页角色动作沿用现有素材来源版本，选择 `idle-front`、`dense-wave`、`dense-dance` 三张原图集；帧序参考项目现有编译脚本。动作离开视口或暂停动效时停止；减少动态效果时显示静止帧。原肖像保留作加载失败回退。
