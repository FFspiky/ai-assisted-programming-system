# 达菲郁陪你验证、解释、独立再做一次

本轮将题目共创串为三个可以回看的阶段：验证 AI 代码、解释自己的判断和修改、在另一道人工关联题上尝试。保留现有题库、三语言执行、深海蓝界面与达菲郁桌宠。此功能并不生成掌握度分数，也不把有限用例通过当成所有输入正确。

## 页面与保存反馈

三阶段入口位于页面标题下，选题、语言与新建记录通过当前题目摘要展开。用例共创和代码质检采用紧凑文字切换；达菲郁在桌面侧栏和手机陪伴条中提供同一套本地提醒。

状态区分别显示账户记录版本、本机草稿和未保存到账户的修改。测试输入与期望可以仅保留在本机；账户版本存在不代表所有表单输入都已上传。本机保存失败时提示勿直接关闭页面；较旧本机草稿含未保存修改时保留输入，并提供账户当前内容供核对。仅在练习页补记帮助、且表单与账户一致时，不额外锁定保存。

复盘顶部呈现实际运行次数、解释状态与关联题正式提交记录。空白解释不显示为“已理解”，旧解释仍保留对应代码标识。帮助自述安排在独立练习实际提交结果下方，重入时可补记同一次尝试的提交；新提交的自述默认留空。

## 学生如何使用

1. 从刷题页进入题目共创，选择输入，核对候选来源、实际运行结果及正式用例范围。也可以跳过预测或暂不判断。
2. 由本人填写修改位置、修改原因、适用边界和仍不确定的部分。空白保持空白，不由 AI 代写贡献。解释绑定当时的代码，代码更新后需要重新核对。
3. 从复盘选择人工关联题，进入独立尝试页。独立页保留目标语言的现有草稿；没有草稿时使用原有语言起始模板，不注入源题答案或 AI 候选。
4. 本页暂时收起 AI 优化、自动补全、共创、分级帮助、历史 AI 建议和聊天。达菲郁的形象、拖动和动作菜单保留。可以随时退出普通练习，当前草稿不丢失。
5. 使用原来的“提交解答”完成真实判题。该本人、同题、同语言且开始后的提交会关联到复盘。关联失败可重试，不需要重新判题。
6. 如实选择帮助情况：尚未填写、未使用帮助、线索或局部帮助、完整参考。后面三项都明确标为本人自述；本站不能证明站外没有帮助。

如果目标已有草稿或历史提交，页面会明确说明本轮并非全新起点，不会清空用户的原记录。完成关联题只能描述一次实际尝试，不自动证明知识或能力迁移。

## 人工关联题

`data/co_create_learning_pairs.json` 使用以下格式：

```json
{
  "version": 1,
  "kind": "curated-related-practice",
  "notice": "由项目人工编排的关联练习；题目相关不代表等难度，完成不证明能力迁移。",
  "pairs": [
    {
      "source_id": "CL-BASICS-01",
      "target_id": "CL-BASICS-02",
      "source_title": "秒数换算",
      "target_title": "数位之和",
      "reason": "分别练习时间单位与十进制数位拆分，比较整除、取余、零值及输入范围。",
      "concept": "整除与取余"
    }
  ]
}
```

目前题库 10 类、每类 6 道题，共 30 对、60 条双向关联，每道题恰有一个关联目标。由项目人工依据题意、知识点与难度编排，未调用模型生成题目或答案。关联理由明确提示不同算法或难度跨度：例如无权与带权最短路需要不同队列策略，队列日志与柱状图仅是同类数据结构拓展，不能直接视为同构变式。

## 独立页与接口约定

独立页由服务端返回：

```text
/practice.html?problem=<target>&language=<language>&co_create_session=<session_id>&transfer_attempt=<attempt_id>
```

仅 URL 参数不能启用独立模式。脚本等待当前用户与题目就绪后读取本人记录，校验会话、尝试、目标题和语言一致才启用；访客、失效或不匹配记录恢复普通练习。题目、语言或登录账号变化也退出独立模式并清除关联查询参数。普通练习没有这些有效参数时不受影响。

| 接口 | 用途 |
|---|---|
| `GET /api/co-create/sessions/<sid>/learning/transfer/<aid>` | 读取本人尝试、来源、目标、当前会话版本及复盘链接 |
| `POST /api/co-create/sessions/<sid>/learning/transfer/<aid>/submission` | 以 `revision`、本人 `submission_id` 与 `help_usage` 关联真实判题 |

提交关联幂等；遇版本冲突，前端读取一次最新版本并重试一次。请求失败时保留待关联的提交，明确提示“判题结果已保存，关联未完成”。改变帮助自述后，可以再次关联同一个提交，不调用执行或 AI 接口。

`window.PracticeTransfer` 提供只读 `active`、`pending`、`blocksAI`、`context` 及 `notifyBlocked()`；状态变化派发 `practice:transfer-mode`。既有控制器据此阻止后台补全、快捷键、优化、帮助和聊天，不更改账号长期帮助偏好。

## 验证范围与限制

- Node 控制器测试覆盖正常页不受影响、访客及非法链接恢复、本人题目语言校验、保留已有草稿、退出与语言变化、异步旧响应、真实提交关联请求、默认帮助未填写、幂等更新自述、版本冲突和失败重试。
- 人工关联表校验覆盖全部 60 道规范题目、标题、同分类、双向关系、无自身关联及无代码答案字段。
- 后端检查所有权、正式提交归属、开始时间、题目语言和会话版本；运行与判题仍走原 Docker 隔离执行链。
- UI 暂时收起本站 AI 入口是一种学习安排，不构成考试监考或站外无帮助证明。
- 本轮功能和自动回归不能代替真实用户研究。尚不能宣称“已完成五人验证”“学习效率提高”或“已经掌握”。后续需使用同模型、同信息条件的探索性观察，诚实保留失败与无法解释的结果。
