## 已完成的体验

根据 10 月 12 日的界面反馈，已移除宣传横幅、独立右栏、“进入循环演示”和“载入错误示例”按钮。题面只保留正式题目内容；题目来源与 AI 使用记录保留在项目文档，不放进做题界面。

帮助记录保存到该次提交，刷新可恢复最近提交与已请求过的提示，提示默认折叠；草稿按用户、题目和语言保存在当前浏览器。隐藏用例只显示状态，输入、答案、错误信息不会发送到模型或学生端。历史提交没有证据快照时要求重新提交，不补造证据。

## 三分钟 F1 + F2 演示

1. 登录自己的账号，打开 `http://127.0.0.1:5005/practice.html?problem=DEMO-01`。
2. 将下方错误代码输入编辑器，点击“提交解答”。公开输入为 3，预期为 6，实际为 3；首个失败后停止，剩余两个用例明确显示未执行。
3. 先点击“概念线索”，只查看概念与自查问题。再选择“定位与解释”，点击“查看依据”，展示用例与提交快照行的关联；选择“局部修改”后才出现候选片段。可主动跳到“完整参考”，但代码仍标为待验证。
4. 刷新页面，展示证据和草稿仍在；已请求的提示以折叠记录恢复，不自动展开高层答案。
5. 将 `range(1, n)` 改为 `range(1, n + 1)`。先展示“证据对应上次提交”的提示，再重新提交，展示全部 3 个用例通过。

```python
n = int(input())
total = 0
for i in range(1, n):
    total += i
print(total)
```

演示重点是“运行事实 → 主动选择帮助程度 → 人工检查修改 → 实际复测”。AI 解释不能替代判题。当前局部代码为只读建议，不包含 F3 的 Diff、采纳/拒绝、撤销或时间线。

补充题直接替换 URL 中的题号：

| 题号 | 错误现象 | 参考修正 |
| --- | --- | --- |
| DEMO-01 | 循环不含右端点，3 得到 3 而非 6 | `range(1, n + 1)` |
| DEMO-02 | `text[len(text)]` 引发 IndexError | `text[len(text) - 1]` |
| DEMO-03 | 两次 `input()` 直接相加，2 和 3 得到 23 | 输入时用 `int(input())` 转换 |

三题由项目材料定义，AI 辅助编写，非外部题库搬运；这些来源信息保留在本文。参考修正均已通过各题当前 3 个用例。学习模式默认关闭自动补全。主动切换“自由辅助”后开启，Tab 接受、Esc 取消；切回学习模式清空补全缓存。AI 优化在学习模式下遵守所选帮助程度。普通聊天独立于辅助模式，可正常请求完整代码；仍需主动点击“附带当前练习”才附带上下文。

## F3 最小修改复盘（2026-10-13）

使用入口：登录 → 刷题提交 → 在结果区主动请求「局部修改」或「完整参考」→ 展开「查看修改差异」→ 采纳/拒绝 → 必要时撤销 →「重新提交验证」→ 展开「练习过程」。已有代码被继续编辑时，采纳/撤销不会覆盖，需自行核对。旧提示缺少精确修改范围时只读，重新请求可生成新版建议。
