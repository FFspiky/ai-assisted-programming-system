## 三分钟 F1 演示

1. 登录自己的账号，打开 `http://127.0.0.1:5005/practice.html?problem=DEMO-01`。
2. 将下方错误代码输入编辑器，点击“提交解答”。公开输入为 3，预期为 6，实际为 3；首个失败后停止，剩余两个用例明确显示未执行。
3. 点击“分析错误”，等待真实 AI 结果。点击“查看依据”，展示用例与第 3 行 `range(1, n)` 的关联。
4. 刷新页面，展示提交证据、诊断和草稿仍在。
5. 将 `range(1, n)` 改为 `range(1, n + 1)`。先展示“证据对应上次提交”的提示，再重新提交，展示全部 3 个用例通过。

```python
n = int(input())
total = 0
for i in range(1, n):
    total += i
print(total)
```

演示重点是“运行事实 → AI 疑似原因 → 人工检查修改 → 实际复测”。AI 解释不能替代判题；本轮不展示尚未实现的三级提示或时间线。

补充题直接替换 URL 中的题号：

| 题号 | 错误现象 | 参考修正 |
| --- | --- | --- |
| DEMO-01 | 循环不含右端点，3 得到 3 而非 6 | `range(1, n + 1)` |
| DEMO-02 | `text[len(text)]` 引发 IndexError | `text[len(text) - 1]` |
| DEMO-03 | 两次 `input()` 直接相加，2 和 3 得到 23 | 输入时用 `int(input())` 转换 |

三题由项目材料定义，AI 辅助编写，非外部题库搬运；这些来源信息保留在本文。参考修正均已通过各题当前 3 个用例。自动补全默认关闭。

## 当前边界

- 模型引用的 ID 与行号已验证，解释的语义仍可能有误。保留“疑似原因”标识，最终状态由执行判题给出。
- “取消等待”中止浏览器等待，服务端已发出的请求可能继续完成并保存；稍后可恢复记录。网络失败不会显示伪造诊断。
- 执行耗时是包含容器启动的服务总耗时，不声称是纯代码性能。C++ 每个用例仍独立编译，编译/运行分段耗时为 null。
- `text` 是默认判题模式；历史浮点题需在管理员编辑页明确选 `float`。整数模式精确比较，浮点容差不应用于所有题目。
- 当前提供最近提交恢复，完整提交关联、提示升级、Diff、采纳/撤销及时间线留给 F2/F3。普通聊天和优化仍是原有辅助入口，不能宣称已具备学习模式控制。
- 2026-10-13 已将问卷答案接入学习路径提示词，页面入口仍暂停，完整产品流程待单独验证。学习时长、积分并发、长期学情等 P2 工作不作为本轮创新效果证据。
- 容器不挂载项目或宿主目录，不注入应用密钥，不开放网络；限制单次资源并回收。当前为本机演示执行器，不代表完成公网高并发沙箱部署。
