# 执行证据、分级帮助与修改复盘

## 使用前准备

按 [启动说明](COMPETITION_PREVIEW.md) 初始化独立预览库、构建 Docker 镜像并启动服务。登录后，在个人资料页配置 DeepSeek 官方 Key，或选择已由服务端配置的项目测试 Key。未配置 AI 时仍能运行和提交代码。

## 功能约定

提交代码后展示真实判题结果，公开用例显示输入、预期与实际输出。隐藏用例只展示允许公开的状态，不向模型或学生端发送隐藏输入、答案与错误正文。没有证据快照的记录需要重新提交，不补造运行依据。

用户主动选择「概念线索、定位与解释、局部修改、完整参考」。建议绑定提交快照；编辑器发生变化时，旧证据不会自动变成新代码的验证结果。公开证据不足时明确提示限制，不强行定位原因。

局部建议支持差异预览、采纳、拒绝、撤销和正式复测关联。采纳前检查代码基线，避免覆盖后续编辑；采纳成功仅表示代码已更新，是否通过仍由正式判题决定。

学习模式关闭自动补全；自由辅助模式允许补全。普通聊天独立于帮助层级，题目上下文由用户主动附带。关联练习的独立模式暂时收起本站 AI 帮助，退出后恢复正常使用。

## 演示流程

1. 进入 `/practice.html?problem=DEMO-01`，选择 Python。
2. 输入下方代码并提交，比较公开输入 `3` 对应的预期结果 `6` 与实际结果 `3`。
3. 按需请求概念线索、定位解释或局部修改，核对建议引用的提交和代码行。
4. 查看修改差异并主动采纳，或手动将 `range(1, n)` 改为 `range(1, n + 1)`。
5. 再次提交，查看当次真实判题结果与修改记录。刷新后核对账号记录及草稿恢复。

```python
n = int(input())
total = 0
for i in range(1, n):
    total += i
print(total)
```

其他演示题可使用 DEMO-02 检查字符串索引、DEMO-03 检查输入类型。演示题由项目定义并使用 AI 辅助编写；运行结果以本次执行为准。

## 验证

```sh
python -m unittest discover -s tests
```

浏览器验证按启动说明执行 `npm run smoke`，包含证据定位、采纳撤销、复测、过期保护、帮助控制及窄屏检查。自动化测试使用模型替身，真实 AI 回复需另外核验。有限用例通过不代表全部输入正确，也不能证明学习收益。
